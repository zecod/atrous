# Security

Report vulnerabilities privately through [GitHub's Report a vulnerability](https://github.com/zecod/atrous/security/advisories/new). Don't post exploit details in a public issue.

Include the Atrous version, OS, what you found, steps to reproduce it, and the impact. A small proof of concept helps. Remove secrets and personal data from logs.

Only the latest release is supported.

For how Atrous handles trusted mods, updates and the network, see [security and privacy](docs/security.md).
